## Como executar

1. Clone o repositório e entre na pasta do projeto:

```bash
   git clone https://github.com/xGooro/ProjetoP1_PDM.git
   cd ProjetoP1_PDM
```

2. Instale as dependências:

```bash
   npm install
```

3. Abra o arquivo `src/utils/chaves.js` e troque os dois valores `COLOQUE_SUA_CHAVE_AQUI` pelas chaves verdadeiras:
   - `GEOAPIFY_KEY`: crie uma conta gratuita em https://myprojects.geoapify.com, crie um projeto e copie a sua API key.
   - `PRIMEUI_LICENSE`: obtenha a chave da licença Community, gratuita para estudantes, em https://primeui.dev/licenses/community.

4. Inicie a aplicação:

```bash
   npm run dev
```

5. Abra no navegador o endereço exibido no terminal (normalmente http://localhost:5173).

Ao abrir a aplicação, o navegador pedirá permissão de acesso à sua localização. É preciso permitir para que o RolêRadar funcione.
